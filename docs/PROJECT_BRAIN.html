Trade Vision — PROJECT BRAIN v1.94 · MOCK

Paper trading helper. Reads candles. Judges idea. Suggests practice trades. Never places real broker orders.

The Path
Story: Human hits Analyze → Candle Source loads 1m bars → UI Build cleans pack → HTTP In posts to server → Safety can hard-stop → Snapshot freezes closed bars → Evidence Pack runs 8 tools → Arbiter judges → ORB may propose entry/stop/target → Arbiter judges again → Guidance Out → UI Screen → optional Paper Ledger Record → later Outcome Watcher. Side toys (Jarvis, Kronos, Twin, AI, TrendForge, 9C, Regime, Lag) only show stuff. Live money stays off.

The Connections
  1. Candle Source sends 1m bars to UI Build so UI Build can clean a multi-timeframe payload.
  2. UI Build sends the payload to HTTP In so the server can start one paper run.
  3. HTTP In sends the pack through Safety & Audit so a hard “no” can stop the whole run.
  4. Safety allows the run, then Snapshot Freeze locks closed bars so later tools share one photo.
  5. Snapshot sends frozen bars to Evidence Pack so 8 mini tools can score the idea.
  6. Evidence Pack sends scores to Arbiter (BOSS) so the boss can pick WAIT / WATCH first pass.
  7. ORB Playbook sends entry/stop/target to Arbiter so pass #2 can allow ENTER_PAPER when eligible.
  8. Arbiter sends final_band to Guidance Out so UI Screen can show the human the card.
  9. UI Screen sends Record confirm to Paper Ledger so a fake trade row is saved locally.
  10. Paper Ledger sends paper ids to Outcome Watcher so later bars can mark win/loss; side toys (Jarvis, Kronos, Twin, AI, TrendForge, 9C, Regime, Lag, OpenAlgo, Stock App) only talk to humans for display / dry-run.
